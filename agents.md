# AGENTS

## Подход для каждого треда

1. В начале каждого треда изучить документацию проекта.
2. После каждого выполненного задания проверить, нужно ли внести изменения в документацию и перечень требований; при необходимости внести эти изменения.
3. Вся документация проекта должна храниться в кодировке UTF-8.
